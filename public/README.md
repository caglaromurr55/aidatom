# AİDATOM.COM — Statik Medya & Logo Klasörü

Bu klasör içine ekleyeceğiniz logo ve görseller sitenin tüm sayfalarında doğrudan `/dosya_adi.png` şeklinde kullanılabilir.

## Önerilen Dosya İsimleri:

1. **Ana Logo (Yatay / Renkli):**
   - Dosya Yolu: `public/logo.png` veya `public/logo.svg`
   - Kullanım Yeri: Üst Menü (Header), Giriş/Kayıt ekranları ve Landing Page.

2. **Beyaz / Koyu Zemin Logosu:**
   - Dosya Yolu: `public/logo-white.png` veya `public/logo-white.svg`
   - Kullanım Yeri: Derin Lacivert (`#0F1F3D`) Sol Menü (Sidebar).

3. **Tarayıcı Sekme İkonu (Favicon):**
   - Dosya Yolu: `public/favicon.ico` veya `public/icon.png`
   - Kullanım Yeri: Tarayıcı sekmesinde görünen site logosu/ikona.
